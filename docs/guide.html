repo-create-ext

Chrome / Microsoft Edge 共通の GitHub New Repository ランチャーです。

使い方

  1. 拡張機能をブラウザに読み込みます。
  2. ツールバーの New GitHub Repository をクリックします。
  3. Open github.com/new を押します。
  4. GitHub本体でRepository名・公開範囲などを確認して作成します。

Side Panel

ブラウザの拡張機能メニューから repo-create-ext のSide Panelを開くと、現在のページを離れずにGitHubのNew Repositoryへ移動できます。

Privacy

このMVPはGitHub Token、OAuth credential、Repository dataを保存しません。認証と作成処理はGitHubに委譲します。

Install for development

chrome://extensions または edge://extensions → Developer mode → Load unpacked → リポジトリのフォルダを選択します。
